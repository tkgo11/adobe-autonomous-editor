# Workflow: Interview / Video Podcast / Panel

## Trigger

Use for two or more speakers in conversational content, interviews, podcasts, roundtables, remote calls, or panel discussions.

## Default assumptions

- preserve conversational authenticity;
- favor the active speaker while retaining reaction shots when they add meaning;
- remove technical dead space, restarts, obvious off-topic setup, and redundant repetitions when safe;
- never edit a response so aggressively that speaker intent is distorted.

## Analysis priorities

- speaker diarization and identity mapping;
- active-speaker timing;
- interruptions/overlap;
- reaction moments;
- camera/audio sync;
- remote-call latency or drift;
- per-speaker audio quality;
- retakes and repeated questions/answers;
- topic boundaries and quotable segments.

## Edit plan

1. Sync cameras and external audio; load `multicam-sync.md` when applicable.
2. Build a dialogue-first content cut.
3. Remove irrelevant setup and technical interruptions.
4. Switch angles based on active speaker, reaction value, framing quality, and continuity—not a fixed timer.
5. Use two-shots/split screens only when they improve comprehension or energy.
6. Add topic cards/lower thirds as needed.
7. Produce chapter markers or clip candidates when useful.

## Premiere rules

- prefer multicam sequences for synchronized multi-angle footage;
- retain isolated speaker audio where available;
- use angle changes to hide dialogue trims before adding artificial punch-ins;
- maintain speaker labels/metadata consistently.

## After Effects escalation

Use AE for:

- remote-call layouts;
- animated speaker IDs;
- branded podcast frames;
- tracked graphics;
- stylized quote moments or social cutdowns.

## Audio

Match speaker loudness/timbre as much as practical without over-processing. Repair room/noise differences per speaker rather than applying one destructive global preset.

## QC gates

Reject and repair if:

- camera switch shows the wrong active speaker unintentionally;
- reaction cuts create false implications;
- dialogue overlap is accidentally removed or duplicated;
- speaker sync drifts;
- remote participants differ wildly in loudness;
- edit changes the meaning of a response.
